# ObraListo — archivos de redes

Imágenes y videos que se publican en las redes de ObraListo (Instagram, TikTok y Facebook).
Este repositorio es público solo para que las herramientas de publicación puedan descargar los archivos.

- `posts/`: imágenes de publicaciones y carruseles (1080×1350).
- `reels/`: videos verticales con voz en off (1080×1920).

## Créditos

La voz en off de los reels es **sintética**. Se generó con [Piper](https://github.com/rhasspy/piper)
usando el modelo `es_AR-daniela-high`, entrenado con el dataset de español argentino de
[OpenSLR 61](https://www.openslr.org/61/), licencia
[Creative Commons Atribución-CompartirIgual 4.0 (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/).
